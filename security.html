🛡️ Security

Digital With Nabin — Last Updated: September 18, 2026

1. Our Security Commitment

At Digital With Nabin, your security is our top priority. We use enterprise-grade infrastructure and industry best practices to keep your personal data safe.

2. Account Security

  • Passwords must be at least 6 characters
  • Passwords are hashed and salted
  • Session tokens are managed securely
  • Suspicious login attempts are monitored
  • Account lockout on multiple failed attempts

3. Payment Security

  • Payments via eSewa QR (secure wallet)
  • We never store your bank or card details
  • Only payment screenshots are kept for verification
  • Manual verification by admin before access
  • All transactions are logged for audit

4. Infrastructure Security

  • Powered by Google Firebase (enterprise-grade)
  • 99.9% uptime SLA
  • DDoS protection and rate limiting
  • Automatic backups and disaster recovery
  • Regular security updates and patches

5. Access Control

  • Only authenticated users can access the app
  • Admin panel restricted to verified admin email
  • Role-based access (user vs admin)
  • Firestore rules prevent unauthorized access
  • User data isolated per account

6. Data Protection

  • Data encrypted at rest and in transit
  • Regular security audits
  • GDPR-inspired data handling
  • Compliance with Nepal IT Act 2063
  • Compliance with E-Commerce Act 2081

7. Report a Security Issue

If you find any security vulnerability or suspicious activity, please report it immediately:

  • Do not publicly disclose the issue
  • Send details to the email below
  • We will respond within 24 hours
  • Responsible disclosure is appreciated
nabinkhanal0007@gmail.com

8. Security Tips for Users

  • Use a strong, unique password
  • Never share your login credentials
  • Log out from shared devices
  • Keep your browser updated
  • Enable 2-step verification on Google
  • Report suspicious messages immediately
