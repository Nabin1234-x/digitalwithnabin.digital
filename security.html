🛡️ Security

Last Updated: September 18, 2026

1. Our Commitment

At Digital With Nabin, your security is our top priority. We use enterprise-grade infrastructure and industry best practices to keep your personal data safe.

2. Account Security

  • Passwords must be at least 6 characters
  • Passwords are hashed and salted
  • Session tokens managed securely
  • Suspicious login attempts monitored
  • Account lockout on repeated failures

3. Payment Security

  • Payments via eSewa QR (secure wallet)
  • We never store bank or card details
  • Only screenshots kept for verification
  • Manual admin verification
  • All transactions logged for audit

4. Infrastructure

  • Powered by Google Firebase
  • 99.9% uptime SLA
  • DDoS protection and rate limiting
  • Automatic backups
  • Regular security patches

5. Access Control

  • Only authenticated users can access
  • Admin panel restricted to verified admin
  • Role-based access (user vs admin)
  • Firestore rules prevent unauthorized access
  • User data isolated per account

6. Data Protection

  • Data encrypted at rest and in transit
  • Regular security audits
  • GDPR-inspired handling
  • Compliance with Nepal IT Act 2063
  • Compliance with E-Commerce Act 2081

7. Report a Security Issue

If you find any vulnerability or suspicious activity, report immediately:

  • Do not publicly disclose the issue
  • Send details to email below
  • We respond within 24 hours
  • Responsible disclosure appreciated
nabinkhanal0007@gmail.com

8. Security Tips

  • Use a strong, unique password
  • Never share login credentials
  • Log out from shared devices
  • Keep browser updated
  • Enable 2-step verification
  • Report suspicious messages
